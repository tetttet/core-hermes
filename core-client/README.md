# Hermes

Локальный AI-чат на Next.js и OpenRouter с потоковыми ответами, Markdown и
вложениями.

`Auto · Vision Safe` — локальный маршрутизатор: он выбирает только модели с
подходящей capability и использует `openrouter/free` последним резервом для фото.
Ручная модель сначала повторяется по тому же ID, затем при временном сбое может
переключиться на совместимую резервную модель. API-флаг `allowFallback: false`
оставляет только повторы выбранной модели. Фактический ID сохраняется возле ответа.

Для медленных бесплатных моделей маршрут ждёт до 180 секунд первый токен или
следующий фрагмент потока; общий бюджет запроса — 290 секунд, server route — 300.
Частичный ответ при обрыве не удаляется.

## Запуск

Скопируйте `.env.example` в `.env.local`, добавьте ключ OpenRouter и запустите:

```bash
pnpm install
pnpm dev
```

Приложение будет доступно на <http://localhost:3000>.

## Проверки

```bash
pnpm test
pnpm lint
pnpm build
pnpm check:models
```

`check:models` делает короткий реальный запрос к каждой настроенной модели.
Чтобы дополнительно проверить мультимодальный ввод, передайте пути к тестовым
файлам:

```bash
MODEL_CHECK_IMAGE_PATH=/path/check.png \
MODEL_CHECK_VIDEO_PATH=/path/check.mp4 \
pnpm check:models
```

Видео в интерфейсе перед отправкой преобразуется в четыре ключевых JPEG-кадра.
Это уменьшает запрос и позволяет анализировать ролики без платного ограничения
OpenRouter на нативный video input. Если браузер не может декодировать формат,
приложение использует нативный video input и показывает понятную ошибку при
ограничении аккаунта.
